# LeetSync

LeetSync is a browser extension that silently bridges the gap between a developer's LeetCode grinding and their GitHub profile. It automatically captures successfully passed code submissions on LeetCode and commits them directly to a linked GitHub repository.

Instead of manually copying and pasting solutions after solving a problem, LeetSync acts as an invisible background agent. It verifies that the test cases passed, extracts the source code, formats it, and uses the GitHub API to push the code, keeping the user's open-source contribution graph active and their competitive programming journey well-documented.
